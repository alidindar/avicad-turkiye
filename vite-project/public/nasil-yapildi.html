1

Fikir ve teknoloji

Sayfa tek bir numara üzerine kurulu: video kendi kendine oynamıyor, scroll videoyu sarıyor. Sayfayı kaydırdıkça video ileri gidiyor, geri kaydırınca video geri sarıyor. Böylece ziyaretçi sahneyi kendi hızında yaşıyor.

  • Vite + React 19: proje iskeleti
  • GSAP ScrollTrigger: scroll takibi, bölüm sabitleme ve metin animasyonları
  • ffmpeg: videoyu scrub için yeniden encode etmek (en kritik adım)
2

Scroll'u videoya bağlamak

Hero bölümü pin: true ile ekrana sabitleniyor ve end: '+=500%' ile 5 ekran boyu scroll alanı açılıyor. Her scroll karesinde ScrollTrigger 0 ile 1 arasında bir progress veriyor. Bu değeri video süresiyle çarpıp currentTime'a yazmak yetiyor:

ScrollTrigger.create({
  trigger: container,
  start: 'top top',
  end: '+=500%',
  pin: true,
  scrub: 0.5,
  onUpdate: (self) => {
    if (video.duration && !video.seeking) {
      video.currentTime = self.progress * video.duration;
    }
  },
});

!video.seeking kontrolü önemli: tarayıcı henüz önceki kareye giderken üstüne yeni seek istekleri yığarsanız kuyruk birikir ve takılma başlar.

3

İşin sırrı: video encode

İlk denemede scroll fena kasıyordu. Sebep kod değil, videonun kendisiydi. Sıradan mp4'lerde keyframe birkaç saniyede bir gelir. currentTime ile rastgele bir kareye atladığınızda tarayıcı en yakın keyframe'e gidip oradan itibaren tüm kareleri çözmek zorunda kalır. Scroll başına yüzlerce kare çözmek demek, donma demek.

Altın kural

Scroll-scrub video mutlaka sık keyframe ile encode edilmeli. Keyframe aralığını -g parametresi belirler.

# Gelistirme icin: her kare keyframe, en akici sonuc
ffmpeg -i kaynak.mp4 -c:v libx264 -g 1 -crf 19 -preset fast \
  -pix_fmt yuv420p -an -movflags +faststart public/video/one.mp4

# Web icin: 2 karede bir keyframe, daha kucuk dosya
ffmpeg -i kaynak.mp4 -c:v libx264 -g 2 -crf 22 -preset fast \
  -pix_fmt yuv420p -an -movflags +faststart one-web.mp4

-an sesi atar (scrub'da ses kullanılmaz), +faststart metadata'yı dosyanın başına taşır ve video ilk saniyede oynamaya hazır olur.

4

Sahne metinleri

Metinler videodan bağımsız birer katman. Her sahnenin bir progress aralığı var (örneğin 0.18 ile 0.36 arası). Progress o aralığa girince sahnenin GSAP timeline'ı oynuyor, aralıktan çıkınca tersine sarıyor. Başlıklar blur ve yukarı kayma ile beliriyor:

const SCENES = [
  { id: 'scene-1', start: 0,    end: 0.18 },
  { id: 'scene-2', start: 0.18, end: 0.36 },
  // ...
];

tl.fromTo(heading,
  { opacity: 0, y: 50, filter: 'blur(16px)' },
  { opacity: 1, y: 0, filter: 'blur(0px)', duration: 1.1, ease: 'power3.out' }
);
5

Performans dersleri

  • Overlay karartmayı gradient animasyonu ile değil, iki katmanın opacity crossfade'i ile yap. Gradient'i her karede yeniden boyamak pahalı.
  • Progress bar'ı width ile değil transform: scaleX() ile büyüt. Transform layout tetiklemez, GPU'da çalışır.
  • Animasyon yapılan katmanlara will-change ipucu ver.
  • Videoyu muted ve playsInline yap, preload="auto" ile baştan yüklet.

Kendin kur

git clone https://github.com/Eneslexi/got-scroll-site.git
cd got-scroll-site/vite-project
npm install
# videoyu 3. adimdaki gibi encode edip public/video/one.mp4 olarak koy
npm run dev
